# GreenHope Foundation

## About the Project

GreenHope Foundation is a responsive website developed for a fictional environmental organisation dedicated to promoting sustainability, environmental awareness, and community involvement. The website provides visitors with information about the organisation's mission, projects, and opportunities to contribute to creating a greener and healthier environment.

The project was designed to deliver a professional, accessible, and user-friendly experience while showcasing modern web development principles. The website features a clean layout, intuitive navigation, environmental imagery, and responsive design that adapts to various screen sizes.

## Website Pages

The website consists of five main pages:

### Home
Introduces GreenHope Foundation, its purpose, and its commitment to environmental conservation and community development.

### About Us
Provides an overview of the organisation, including its mission, vision, values, and commitment to sustainability.

### Projects
Highlights the foundation's key environmental initiatives aimed at improving communities and promoting responsible environmental practices.

### Get Involved
Encourages visitors to participate through volunteering, sponsorship opportunities, and community engagement activities.

### Contact
Provides contact information and communication options for visitors who would like to learn more or get involved.

## Environmental Initiatives

The Projects page showcases four core programmes:

- **Green Streets:** A community greening project focused on tree planting and neighbourhood beautification.
- **Clean & Care:** Community clean-up campaigns that promote responsible waste management.
- **Green Schools:** Educational programmes that teach sustainable living, recycling, and environmental conservation.
- **Future Guardians:** A youth development initiative that encourages young people to participate in environmental and community projects.

## Technologies Used

The website was developed using:

- HTML5 for content structure
- CSS3 for styling and responsive layouts
- JavaScript for interactive functionality
- Git for version control
- GitHub for project management and repository hosting

## Design and Functionality

The website uses a nature-inspired colour scheme consisting primarily of green, white, and neutral tones to reinforce its environmental focus.

### Key Features

- Environmental photography
- Project showcase sections
